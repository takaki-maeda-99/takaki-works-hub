# PS5コントローラー → Teensy 4.0 制御システム

## 概要
PS5コントローラーの入力をシリアル通信でTeensy 4.0に送信し、オムニホイールロボットを制御するシステムです。

## 必要なもの
- PS5コントローラー（DualSense）
- Teensy 4.0（PlatformIOでファームウェア書き込み済み）
- Python 3.7以上

## セットアップ

### 1. Pythonライブラリのインストール
```bash
pip install -r requirements.txt
```

### 2. PS5コントローラーの接続
- PS5コントローラーをUSBケーブルでPCに接続
- または、Bluetoothでペアリング

### 3. Teensy 4.0の接続
- Teensy 4.0をUSBケーブルでPCに接続
- COMポート番号を確認（デバイスマネージャーで確認）

## 使用方法

### 1. スクリプトの実行
```bash
python ps5_controller.py
```

### 2. COMポートの設定
`ps5_controller.py`の33行目でCOMポートを設定してください：
```python
controller = PS5Controller(serial_port="COM3", baud_rate=115200)
```

### 3. 操作方法
- **左スティック**: ロボットの移動（前後・左右）
- **右スティック**: ロボットの回転
- **PSボタン**: シリアル通信のオン/オフ切り替え
- **Ctrl+C**: プログラム終了

## データ形式
Teensyに送信されるデータ形式：
```
L_x,L_y,R_x,R_y\n
```
- `L_x`, `L_y`: 左スティックのX軸、Y軸（-100～+100）
- `R_x`, `R_y`: 右スティックのX軸、Y軸（-100～+100）

## トラブルシューティング

### コントローラーが認識されない
- USBケーブルが正しく接続されているか確認
- Bluetoothの場合、ペアリングが完了しているか確認
- 他のアプリケーション（Steam等）がコントローラーを使用していないか確認

### シリアル通信エラー
- COMポート番号が正しいか確認
- Teensyが正しく接続されているか確認
- 他のアプリケーションがシリアルポートを使用していないか確認

### 動作が不安定
- デッドゾーン値を調整（`deadzone = 0.1`）
- 更新頻度を調整（`time.sleep(0.02)`で50Hz）
